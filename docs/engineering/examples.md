## 适用限制

- 用户切片的 `displayName`、物理删除、覆盖写入与分页界限不自动成为其他实体的业务规则。
- 本地切片没有生产身份系统；不拿它证明合同权限、资金集成或付费内容隔离。
- User 是无关联叶子；涉及真实关联与 ContextRole 时按源设计，不能复制叶子模式省略关联。
- H2、mock 和前端 DOM 测试有各自覆盖，不能替代生产数据库、真实持久化或浏览器联调。
- 当前分层测试不证明未来业务模块已封装。新模块需新增公开契约、禁止访问和事务测试。

复用记录进入当前任务 `dependencyUsage` / `files.reuse` 与 CHECK：说明消费什么、为何适用、重跑什么以及证据限制。上游模式定位见 [固定依据](../../.agents/skills/evidence-task-planning/references/upstream.md)，不复制参考产品业务或旧依赖。
