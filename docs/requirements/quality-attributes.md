# 质量属性与未决边界

本页是质量要求的项目入口。已有安全底线与待定产品目标分开；没有依据的性能、留存、权限或部署指标不填常见默认值。

## 可执行基线

| 标识               | 来源与适用范围                                                                                                           | 约束 / 可观察结果                                                              | 检查入口                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------ |
| QA-LOCAL-ISOLATION | [本地配置](../../apps/backend/src/main/resources/application-local.properties)、[切片契约](../../apps/backend/README.md) | 本地后端绑定回环地址；CRUD 仅在 local/test 注册；不通过代理暴露公网            | 应用 profile/资源隔离测试及运行配置检查                |
| QA-MODULE-BOUNDARY | [模块设计](../architecture/modules.md)                                                                                   | domain 无技术框架依赖；API 不访问 persistent；未来业务模块不可访问他模块私有表 | Gradle 依赖、ArchUnit；实际业务边界按任务增加检查      |
| QA-INPUT-FAILURE   | 用户切片契约                                                                                                             | 非法输入被拒绝，失败不修改数据；不返回 SQL 或内部栈                            | API 独立 HTTP 与应用真实装配测试                       |
| QA-BUSINESS-TIME   | [FM 时间边界](../../.evidence/fm/00-overview.md)                                                                         | 业务事件时间不被通知到达或当前服务器时间覆盖                                   | 相关业务任务的固定时间、截止与迟到场景；未实现不记通过 |
| QA-REPRODUCIBILITY | [项目宪法](../../AGENTS.md)                                                                                              | CHECK 记录 cwd、输入、命令、环境、退出码与源版本                               | [测试指南](../engineering/testing.md)及任务证据        |

## 需要依据的专题

| 标识           | 必须明确的决定                                                 | 阻塞范围                                         |
| -------------- | -------------------------------------------------------------- | ------------------------------------------------ |
| QA-IDENTITY    | 可信身份来源、主体映射、代表权限、实例归属及实时资格检查       | 生产受保护操作，不阻塞纯领域或隔离本地测试       |
| QA-I18N        | 目标语言、界面/用户内容边界、回退、时区、日期和货币格式        | 多语言交付；中英文术语不等于多语言产品需求       |
| QA-AUDIT       | 记录什么、谁可查、敏感字段、留存/删除、完整性与导出要求        | 生产审计；业务履约凭证不能用技术日志替代         |
| QA-DATABASE    | 生产引擎/版本、数据源、隔离级别、迁移与备份恢复目标            | 生产 SQL、并发、运维验收；H2 只提供本地/测试证据 |
| QA-INTEGRATION | 真实凭证取得渠道；如需远程，再确定协议、信任、超时、重试与幂等 | 对应接入任务；外部 Context 不自动要求联网        |
| QA-SLO         | 具体场景、负载模型、数据量、延迟/可用性目标、观测窗口          | 性能与可靠性承诺；不自行指定 QPS、P99 或 SLA     |

上述标识描述未决主题，不是虚构的已批准要求。需要时按用户授权形成专题方案，再在本页和 Guides 导航引用；没有方案时保留实际影响，不建空白文档冒充完成。

## 专题方案的最低内容

每项写清来源、确认状态、场景与非目标、可测量预期、威胁/故障模型、设计取舍、配置边界、验证命令或人工步骤。身份隔离、并发、故障恢复等要求必须有拒绝/失败场景，不只证明 happy path。

安全编码的工程底线见 [安全规范](../engineering/security.md)。任务状态只在计划索引维护；本页不记录任务 done 或测试通过。
