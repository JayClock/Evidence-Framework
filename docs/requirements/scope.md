# 软件职责与范围

## 来源与状态

本页区分业务来源、已有实现和待决定的软件范围，不批准业务模型，也不把存在的代码追认为完整产品交付。

- [发现记录](../../.evidence/discovery.md)与 [FM 概览](../../.evidence/fm/00-overview.md)：专栏订阅、支付、内容访问、断更退款、免费恢复，以及 CRM 电话销售绩效协议。
- [模型入口](../../.evidence/fm/model.json)：模型文件不保存审核状态；执行前核对实际源。
- [API 设计](../../.evidence/api/api.json)：当前是 `api.column-subscription`，覆盖整体 FM 的资源、能力与 HTTP 契约；业务接口契约，不是已部署接口清单。
- [用户切片说明](../../apps/backend/README.md)及其源码/测试：本地基础工程行为；其显示名称等软件字段不假称来自 FM。
- 移动支付订阅主链由当时的用户交付指令授权（成功登记包含全部 11 个必填字段的订阅合同后，系统自动派生付款要求并调用 local/test 支付端口）；其实施计划的正式 API 投影只包含 `capability.register-subscription-reader`、`capability.list-subscriptions-reader`、`capability.read-subscription-reader`、`capability.read-payment-reader` 及其支撑资源。该切片的 FM/API/计划来源曾随模型收敛移出仓库（提交 `0e76410`），并按用户 2026-09-20 指令从 Git 历史恢复；其 2 个基础任务已完成、6 个实施任务保持 planned。
- 电话销售绩效协议主链是本次授权的软件切片，授权来源为用户交付指令；计划的 `authorizationRefs` 引用[建模评估](../../.evidence/fm/crm-assessment.md)，收敛状态见缺口 `GAP-SCOPE-CRM`。

## MVP 与非目标

当前可指认的工程范围是 Harness、本地用户基础切片、移动支付订阅主链与电话销售绩效协议主链。两个业务切片由各自当时的用户交付指令决定；它们不等于全局业务 MVP 已经收敛。内容访问、退款、恢复、预付费与异常履约仍待后续取舍。

以下不由本批次新增：前端业务页面、生产身份系统与生产数据库、真实支付协议与机构验签、协议参与方实例核验与 403、未达标后果（补偿、处分、违约）、周度进度检查、客户档案生命周期与读写接口、独立发布的后端服务。它们是否纳入软件交付须有需求或技术依据；未定不等于永久排除。

移动支付订阅主链的 FM/API/计划内容按用户指令从 Git 历史恢复，恢复不等于该切片其余任务自动获得继续执行授权；继续执行须核对 [delivery 流程](../../.agents/skills/evidence-delivery/SKILL.md)与计划状态。

## 下游使用

[故事与验收](stories.md)只登记有依据的需求或实现核对项。规划可以设计候选切片，但执行前须核对来源授权、局部缺口和审核状态。API 覆盖完整也不能替代软件范围决定。本次切片的授权、非目标与未决项只在本页与故事维护，计划索引引用而不复制。
