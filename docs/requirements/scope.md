# 软件职责与范围

## 来源与状态

本页区分业务来源、已有实现和待决定的软件范围，不批准业务模型，也不把存在的代码追认为完整产品交付。

- [发现记录](../../.evidence/discovery.md)与 [FM 概览](../../.evidence/fm/00-overview.md)：专栏订阅、支付、内容访问、断更退款与免费恢复。
- [模型入口](../../.evidence/fm/model.yaml)：当前 `modelStatus: draft`、`stakeholderReview.status: pending`；执行前核对实际源。
- [API 设计](../../.evidence/api/api.yaml)：业务接口契约，不是已部署接口清单。
- [用户切片说明](../../apps/backend/README.md)及其源码/测试：本地基础工程行为；其显示名称等软件字段不假称来自 FM。

## 软件职责矩阵

| 范围               | 当前事实                                  | 软件责任及边界                                               |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------ |
| 业务建模 Harness   | 已有 Skills、交互扩展、校验脚本           | 按授权保存发现、维护 FM/API、规划与记录检查；不替人工批准    |
| 本地用户基础切片   | 已有 ID / displayName CRUD 源码及分层测试 | 本地登记和检索用户资料；不提供生产注册、登录或合同授权       |
| 前端               | 已有用户 API 导航页                       | 提供链接，不是完整用户管理或订阅操作界面                     |
| 专栏订阅与内容访问 | FM/API 已描述业务                         | 本次软件执行、判断、接收结果或辅助人工的具体职责仍需范围确认 |
| 断更退款与免费恢复 | FM/API 已描述责任与凭证                   | 不从业务义务自动推导自动划款、审批流或新的资金义务           |
| 移动支付           | FM 有外部机构资金结果                     | 凭证来源不自动等于网络集成；渠道、验签和可靠性需要依据       |
| 预付费账户         | FM 有余额抵扣与资金证明                   | 已有模型不证明账本、并发扣减或生产数据库已实现               |

## MVP 与非目标

当前可指认的工程范围是 Harness 与本地用户基础切片。业务 MVP 尚未在本页作出取舍，不自动把整个 FM 或所有 API 转为已批准开发范围。

以下不由此次前馈重构新增：生产身份系统、外部支付协议、多语言产品支持、法定审计留存、生产数据库选型、独立发布的后端服务。它们是否纳入软件交付，须有需求/技术依据；未定不等于永久排除。

[故事与验收](stories.md)只登记有依据的需求或实现核对项。规划可以设计候选切片，但执行前须核对来源授权、局部缺口和审核状态。API 覆盖完整也不能替代软件范围决定。
