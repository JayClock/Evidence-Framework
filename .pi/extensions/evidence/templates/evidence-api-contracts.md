# API 契约

## 约定

定义基础路径、内容类型、时间格式、ID、分页、幂等和版本策略。

## 端点目录

| 端点 | 方法 | 用例/故事 | 请求 | 成功响应 | 失败响应 | 权限 |
| :--- | :--: | :-------- | :--- | :------- | :------- | :--- |

覆盖 MVP 所需端点，不为了满足数量制造无业务价值的 CRUD。

## 请求与响应 Schema

为每个端点给出足够精确的 JSON 示例、字段必填性和约束。

## 错误模型

定义统一错误结构、业务错误码、HTTP 状态和可安全展示的信息。

## 契约测试

说明前后端如何验证兼容性和破坏性变更。

## 模型追溯与事件契约

引用 FM Context/Entity/Rule ID 及适用的 Fulfillment/Evidence，说明 DDD Command/Operation/状态迁移 gap 如何投影为 API 行为；不得把 endpoint 写成 FM 实体。领域事件的传输 Schema、排序、重试、重复消费及敏感数据策略在此设计，不写回模型事实。
