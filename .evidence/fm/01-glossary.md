# 统一术语

| 术语             | 含义                                                             |
| ---------------- | ---------------------------------------------------------------- |
| 专栏             | 跨上架版本保持身份的订阅内容产品，用 column_id 定位              |
| 上架版本         | 一次发布或重新上架所提供的内容版本，用 edition_id 区分           |
| 章节             | 专栏特定版本下可独立申请访问的内容单元                           |
| 订阅合同         | 读者和运营方对专栏版本、成交金额及履约期限的约定                 |
| 付款请求         | 运营方要求读者在约定区间内支付全部订阅费的凭证                   |
| 合格付款证明     | 对匹配订阅、读者、标的、金额、币种及期限的实际资金结果的证明约定 |
| 移动支付成功凭证 | 支付机构对实际扣款成功结果负责的具体凭证                         |
| 预付费抵扣凭证   | 账户服务方对余额扣减、实扣金额和扣后余额负责的具体凭证           |
| 内容访问请求     | 读者对指定专栏、版本、章节提出的本次访问主张                     |
| 内容提供凭证     | 证明指定内容已经向该读者提供并可检索，不证明读者已经阅读         |
| 断更下架记录     | 核验约定更新日、持续缺失内容、改期情况和下架事实的补充凭证       |
| 退款请求         | 已付款读者依据断更事实提出的全额返还主张                         |
| 退款到账凭证     | 证明钱款实际到达收款方，不是退款指令受理回执                     |
| 重新上架记录     | 证明同一专栏的新版本已重新提供的补充凭证                         |
| 免费恢复请求     | 原退款读者要求免费恢复同一专栏新版本访问资格的主张               |
| 免费恢复凭证     | 证明指定版本访问资格已恢复且实际收费为零                         |
| 待定             | 请求已形成，当前还不足以判断按时完成或违约                       |
| 完成             | 具体证据满足该请求的完成规则；不是单据登记成功的同义词           |
| 违约             | 已有事实满足约定的违约条件，后续补偿不删除原责任记录             |
| 证明角色         | 可由不同合同的实际时刻凭证扮演的证明插槽，不是一份新单据         |
