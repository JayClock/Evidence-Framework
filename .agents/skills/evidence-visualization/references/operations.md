# 运行与故障排查

## 运行环境

完整保留 Skill 的 `scripts/`、`assets/` 和文档；测试还需要 `tests/`。生成器使用 Python 3.10+ 标准库，FM/API CLI 与依赖由可定位的 FM 安装包提供，两包无需相邻。缺少软件时报告环境限制，不自动安装。

生成与浏览器命令见 [入口](../SKILL.md)。输入为 `.evidence/fm/` 与可选 `.evidence/api/api.json`，输出为 `.evidence/views/index.html`；临时编译和 API 投影保持正式 generated 不变。联合模式增加 `--require-api`，缺 API 返回非零并保留旧页；独立模式可生成仅 FM 页面。HTML 直接在浏览器打开，无需服务器。

## 失败处理

| 情况                              | 处理与出口                                                                         |
| --------------------------------- | ---------------------------------------------------------------------------------- |
| FM/API 未通过或输入在生成期间变化 | 保留错误与旧页，停止发布；规则和预期保持原样，输入稳定后复验                       |
| 输出不是本工具拥有的文件          | 拒绝覆盖，由用户决定后续；不自动迁移、备份或删除                                   |
| 页面停留在加载提示                | 确认打开的是产物，运行浏览器回归并检查脚本错误与 CSP；资源修复需授权，修后重新生成 |
| 引用显示未解析                    | 核对正式对象和显式引用映射；业务有效性由 FM/API CLI 判断，不按名称猜测目标         |
| 没有合同、场景或 API              | 展示实际对象，相关检查报告不适用或未执行，保持空态                                 |

保持 CSP 和脚本哈希完整，不添加 unsafe-inline，不手改或格式化生成 HTML；内嵌块的 prettier-ignore 保护其空白不被重写。旧页仍可保留，但不能证明当前输入有效。

## 自动验证

维护生成器或资源时按影响选择回归；普通页面生成执行入口中的最终 HTML 浏览器检查。

```bash
"$PYTHON" -B -m unittest discover -s "$VISUAL_SKILL_DIR/tests" -v
"$PYTHON" -B -m unittest discover -s "$VISUAL_SKILL_DIR/tests/portability" -v
node --test "$VISUAL_SKILL_DIR/tests/business-graph.test.mjs"
# 维护仓库提供 jsdom；它不是安装包运行依赖：
node --test "$VISUAL_SKILL_DIR/tests/request-detail.test.mjs"
node "$VISUAL_SKILL_DIR/tests/review-browser.mjs" "$PROJECT_ROOT/.evidence/views/index.html"
```

隔离安装测试通过 `EVIDENCE_FM_SKILL` 指定 FM 包；省略时使用测试包相邻位置。浏览器测试要求 Node.js 22+，默认尝试 macOS 标准 Chrome，可用 `CHROME_BIN` 指定已有浏览器，不自动下载。

## 验证覆盖

具体显示规则由 [展示契约](visual-review.md) 维护，运行时按下表定位证明边界，避免把一个 suite 的通过当成全部验证。

| 风险         | 适用回归与观察                                                                                                                                                                                                                  |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 对象与归属   | 生成器和模型图回归：白名单投影、完整对象／关系、真实端点、上下文与履约边界、归属包含、空态、环与悬空引用、玩家及共享确认只出现一次、输入不变性                                                                                  |
| 详情与引用   | Request DOM 与浏览器回归：三组导航及 API 子组、Context 单一折叠组、搜索和属性定位、专用详情、普通对象双区块、请求条件与显式完成凭证、违约后续未声明空态、派生解释及默认折叠表达式、引用穿透和返回恢复；没有显式来源流转时不推断 |
| 图形与交互   | 模型图与浏览器回归：仅角色扮演带箭头、真实基数和时间字段、简化／标准模式、缩放、键盘导航、一跳高亮与焦点优先、最内层边界命中、图例真实类型／示例／线型、模式切换保留展开、不新增导航历史                                        |
| 布局与可读性 | 浏览器几何检查与截图：全部详情表格的表头／内容／链接居中、不同高度单元格、节点文字与责任角标居中、长名称、多行、五个时间字段、窄屏局部滚动与无溢出；合成输入不写回 FM/API                                                       |
| 安全与发布   | 生成器、隔离安装及浏览器回归：文本转义、CSP、发布归属保护、输入变化时拒绝发布、安装包与源不变；脚本错误、外部请求或检查期间文件变化均失败                                                                                       |

## 证据限制

浏览器回归记录对象数量、HTML SHA-256、不适用项与截图目录。截图留在系统临时目录，人工核对文字、布局和语义后交接；高亮、图例、请求条件和窄屏展开态按实际覆盖查看。

完成时，命令、退出码、当前 HTML 摘要、截图与未执行项能定位。日志和摘要留在工作台之外；断言对象存在不证明内容可读，页面没有原始材料也不等于业务数据脱敏。业务批准与运行时接口验证仍需各自依据。
