# 运行与故障排查

## 运行环境

完整保留 Skill 的 `scripts/`、`assets/` 和文档；测试时还需要 `tests/`。生成器自身只使用 Python 3.10+ 标准库，FM/API CLI 的依赖按各自安装包满足。不自动安装软件，不要求三个 Skill 相邻。

```bash
"$PYTHON" -B "$VISUAL_SKILL_DIR/scripts/generate.py" \
  --project-root "$PROJECT_ROOT" \
  --fm-skill "$FM_SKILL_DIR" \
  --api-skill "$API_SKILL_DIR"
```

输入为项目 `.evidence/fm/` 与可选 `.evidence/api/api.json`，输出为 `.evidence/views/index.html`。临时编译和 API 投影不覆盖已有 generated 目录。直接在浏览器打开 HTML，无需启动服务器。

## 失败处理

- FM/API 未通过：保留真实错误，不修改规则或预期；已有工作台不代表当前输入有效。
- 输入在生成期间变化：不发布，待编辑完成后重新生成。
- 输出不是本工具拥有的文件：拒绝覆盖；由用户明确决定如何处理，不自动备份迁移或删除。
- 页面停留在加载提示：确认打开的是产物而非模板，运行浏览器回归，核对脚本错误与 CSP。修改资源后重新生成，不移除 CSP，也不对脚本添加 unsafe-inline。
- 引用显示未解析：核对对应对象和显式引用映射，不靠名称猜测目标；业务源是否有效由正式 CLI 判断。
- 没有合同、场景或 API：正常展示实际领域对象，相关检查为不适用或未执行，不造数据。

不要手改或格式化生成 HTML。生成页的内嵌块带有 prettier-ignore，避免空白变化破坏脚本哈希。

## 自动验证

```bash
"$PYTHON" -B -m unittest discover -s "$VISUAL_SKILL_DIR/tests" -v
"$PYTHON" -B -m unittest discover -s "$VISUAL_SKILL_DIR/tests/portability" -v
node --test "$VISUAL_SKILL_DIR/tests/business-graph.test.mjs"
node "$VISUAL_SKILL_DIR/tests/review-browser.mjs" "$PROJECT_ROOT/.evidence/views/index.html"
```

隔离安装测试通过 `EVIDENCE_FM_SKILL` 接收 FM 包位置；省略时使用测试包相邻的 FM Skill。浏览器测试要求 Node.js 22+，默认尝试 macOS 标准 Chrome 路径，也可设置 `CHROME_BIN`。不自动下载浏览器。

浏览器回归记录对象数量、HTML SHA-256、未适用项与截图目录。它核对单张画布的完整对象／关系覆盖、真实端点、仅角色扮演带箭头、无流程列标题、上下文边界完整性及归属包含关系、空上下文与边界名称导航、玩家与共享确认不复制、责任角标、简化／标准图的字段与基数、缩放及键盘导航，并遍历全部对象，验证业务结构／验证场景／API 三组导航及 API 子组、Context 仅一个折叠组且无独立对象条目、上下文搜索定位、无重复条目、辅助对象的搜索及图上连线／专用详情入口、独立对象／空态／环形归属、业务对象双区块与属性定位、所属上下文定位不切换正文或新增历史、专用详情引用、规则说明、图上外部证明、正确反例、文本安全及窄屏；页面脚本错误、外部请求或测试期间文件变化均失败。截图留在系统临时目录，人工检查文字、布局和语义后再交接。

高亮回归逐一检查对象的一跳关联、上下文内部对象与连线、责任角标、连线端点、键盘优先及清除，不允许传递扩散或改变关系样式。真实鼠标命中验证最内层边界及对象优先，Tab 验证焦点优先；截图包含对象和上下文高亮。

居中回归检查全部详情表格的表头、内容和链接对齐，实测不同高度单元格的几何中心；图上文字块及角标按实际边界双向居中，覆盖两种显示模式、长名称、多行及五个时间字段的合成输入和窄屏。合成输入不写回 FM/API。

图形图例回归验证当前类型完整且不增项、示例名称与责任引用来自模型、颜色与主图一致、连线方向及线型、原生键盘展开、模式切换保留展开、窄屏不溢出，以及主图仍只有一个 SVG。单测另覆盖空模型和不适用类型；截图包含对象图例、上下文与连线图例、窄屏展开态。

测试日志与摘要不嵌入工作台。输出没有原始材料不等于业务数据脱敏，仍须按项目权限保管。
