# FM / API 可视化审核

仅在用户要求“生成可视化”“视觉展示”“生成审核页”等产物时执行。只讨论展示方式时给建议，只校验时不生成文件；普通建模结束不自动启动可视化。视图只读，不是新的业务事实源、审批关卡或软件系统。

## 生成方式

采用 **Python 生成自包含 HTML**：当前 YAML → 真实校验与重新编译 → JSON 投影 → `.evidence/views/index.html`。使用本 Skill 的 `scripts/generate.py` 和 `assets/`，不在业务项目复制生成器。先定位安装资源和依赖；项目根独立传入，不向 Skill 安装目录写项目产物。

```bash
"$PYTHON" -B "$VISUAL_SKILL_DIR/scripts/generate.py" \
  --project-root "$PROJECT_ROOT" \
  --fm-skill "$FM_SKILL_DIR" \
  --api-skill "$API_SKILL_DIR"
```

安装包不完整或缺少依赖时报告工具限制，不假装已经执行。没有 API 设计时只展示现有 FM，不为了视图创建接口或合同。

## 页面内容

1. **业务总览**：Cytoscape.js 以简化业务图为默认入口，突出 Evidence 责任链，同时保留当前责任直接关联的 Party、Thing 与 Role；标准建模图展开全局 Participant、Role、时间类型与关系基数，完整对象图仅用于排查。简化只减少全局噪声，不省略当前业务的三类核心元素。上下文地图保留角色扮演、证明依赖、对象引用与凭证先后的语义。实际模型关系与展示用责任连线区分，不手写另一套模型。
2. **合同与履约**：按 Contract → Fulfillment → Request／Confirmation 展开责任。请求卡显示 `started_at · expired_at`，确认卡显示 `confirmed_at`，合同卡显示 `signed_at`；显示责任角色、完成／违约规则和空缺确认，不将缺失内容补成模型事实。变化点只消费已声明的 `businessPatterns`。
3. **场景时间线**：SVG 展示当前场景中的请求区间、实际确认时刻、basedOn 依赖和固定 asOf；正常、边界、违约按实际场景切换。真实时间轴与等距事件轴明确区分，后者不表达实际持续时间。显示预期／实际值；规则返回 false 不自动等于校验失败。
4. **规则与数据追溯**：字段、CEL 规则、绑定、派生目标及 AST 提取的依赖可互相定位。展示公式而不在浏览器中重写或执行另一套业务规则。
5. **接口矩阵**：按角色筛选，按资源、URI、方法等文本搜索，查看请求响应、幂等、实例约束及 HTTP 消费流程。保留 `runtimeValidated: false`，不提供真实接口调用按钮。
6. **全部 YAML 索引和详情侧栏**：所有业务节点、关系、规则、场景和接口可回到对应文件原文。区分当前输入与历史派生快照；文件数量从实际目录读取，不硬编码某个案例的统计值。

## FM 图例

- Evidence：使用 `#ef5b78` 强调的矩形，必须同时显示业务名称和凭证 stereotype；标准图补充类型时间。
- Participant：使用 `#70a17b` 强调的矩形，包括具体 Party／Thing；具体类型仍以文字标识。
- Role：使用 `#d58a00` 强调的矩形，区分 Party Role、Domain Role、第三方角色和 Evidence Role。
- Context：虚线边界框；嵌套表示责任归属，不把视觉包含关系当作新的模型关系。
- `precedes` 使用有向实线并显示有来源的关系名称；标准图显示两端基数。`plays_role` 使用虚线，`uses_role` 使用点线。颜色与线型之外保留文字，满足黑白和无障碍阅读。

## 离线与校验纪律

- 把数据、CSS、前端脚本和图形库全部嵌入一个 HTML。图形库使用固定版本并保留许可证；页面运行不依赖 CDN、网络请求或后端。
- JSON 嵌入转义 HTML 结束标签；业务名称、CEL 和 YAML 原文按文本渲染，不通过 innerHTML、eval 或动态脚本执行。禁止上传业务数据。
- 消费当前源 YAML 时重新运行 FM 检查；从本次输入重新生成编译模型、追溯、时间线和适用场景结果。有 API 时通过其正式 CLI 重新投影，不拿旧 generated 文件宣称当前有效。
- 写出前复核输入摘要和校验结果；校验失败或生成期间输入变化，不覆盖已有成功视图，不通过修改业务规则或场景预期解决展示问题。
- 输出仅覆盖生成器拥有的视图文件，不改 FM、API 源 YAML、历史检查报告、宿主状态或业务审核状态。页面显示真实生成时间、输入摘要和机器检查状态；离线页无法自动感知后续文件变化，修改后须重新生成。
- 浏览器实际验证筛选、图点击、场景切换、规则详情、接口详情和 YAML 原文；验证无运行错误、无外部请求，检查截图。没有场景、规则或 API 时区分不适用与失败。未执行的检查照实报告。
- CSP 使用最终内联脚本完整内容的摘要；不格式化生成 HTML。模板内嵌块保留 `prettier-ignore`，防止空白改变导致脚本被拦截；故障排查见 [运行说明](operations.md)。
