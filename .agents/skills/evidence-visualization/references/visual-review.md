# 工作台设计

## 产物契约

输出单个 `.evidence/views/index.html`，内嵌样式、脚本和业务投影；不加载第三方图形库、CDN、远程字体或服务。生成方法见 [Skill](../SKILL.md)，故障处理见 [运行说明](operations.md)。

投影仅包含明确允许的业务字段、对象、引用边、统计及检查结论。输入摘要只在生成进程内用于防止读取期间变更，不进入页面。页面不携带文件内容、文件路径、材料引用、访谈、来源信息、执行命令或历史快照；不提供原文浏览器、Git 比较、下载原始模型或兼容旧页面的逻辑。

## 信息架构

```text
顶栏：Evidence / 业务对象工作台 / 离线只读
左侧：全局搜索
  业务结构：上下文折叠组 → 凭证、参与者、角色、规则
  验证场景：场景入口，凭证在场景详情中查看
  API：接口能力 / 接口资源 / 调用流程
主区：面包屑与返回 / 名称与 ID
  业务对象：所属上下文 / 业务属性
  规则、关系、场景与 API：各自专用详情与引用
```

概览展示整体业务模型图，连接全局结构与对象详情；同时显示合同边界、业务对象、规则、场景、API 能力的真实数量，以及各机器检查的实际状态。业务对象计数只含凭证、参与者与角色，上下文是容器，不计入业务对象。不把数量多或检查通过表达为业务建模完成。

左侧只提供业务结构、验证场景、API 三组导航；业务结构按 `contextRef`、`parentContextRef` 组织，独立参与者和无可解析归属的业务对象保留在同组，visited 集合保证环形归属可终止且同一对象只列一次。Context 只显示为折叠组标题，不在组内重复列出，也不提供独立详情或属性；空上下文仍是折叠组。API 子组为接口能力、接口资源、调用流程；无数据的主组显示空态。业务关系从图上连线或搜索进入，场景凭证从验证场景进入，响应表示和实例绑定从接口详情进入，不作为独立栏目平铺。

全局搜索覆盖全部对象并支持上下文定位，保留稳定 ID；上下文命中是定位入口，不是对象详情入口。业务对象详情聚焦归属和属性，专用详情保留规则、场景、关系和 API 引用。属性 ID 使用“对象 ID#属性名”，只在所属对象详情中阅读，保留搜索和引用定位。属性搜索结果显示所属对象名称与 ID，以区分同名字段；选中属性或点击规则/API 字段引用，打开所属对象、高亮并聚焦对应属性行。面包屑保留属性层级，返回恢复属性定位，复制仍得到属性 ID。

## 整体业务模型图

- 全局模型是一张完整 SVG 画布，默认展开全部凭证、参与者、角色及正式关系。不使用边界入口卡片、范围切换或端点汇总。Context 以带有真实名称的背景边界呈现，不是对象节点或关系端点；领域与合同为外层边界，履约边界嵌套在所属合同内，空上下文也保留。
- 按合同、请求及确认／证明组织位置，不显示流程列标题。上下文边界仅包住真实归属对象与子上下文，不按使用关系把外部玩家或共享确认塞入消费方；边界名称可点击及键盘定位并展开对应折叠组，当前正文、历史与画布状态不变。没有直接确认时展示已有证明角色，不补造凭证。共享确认及跨合同玩家只画一次，所有连接指向真实对象。位置不表示执行顺序。纯领域与无履约边界展示实际对象，不虚构合同主线。
- 简化图默认显示对象名称。凭证为矩形，参与者和普通角色为圆角节点；凭证角色为角色样式的矩形。凭证责任方使用右上角可点击角标，合同双方用关联线表达；均由已有“凭证责任方／合同责任角色”显式投影取得，不从名称或场景执行人猜测。证明角色不附加凭证责任角标。
- 节点框内的名称、类型及时间字段逐行水平居中，整个文字块按实际渲染边界垂直居中；单行、多行及省略后的名称使用同一规则。责任角标文字在角标内双向居中。上下文标题及连线基数保持原位置。
- 标准图增加类型、凭证已有业务时间字段以及正式关系基数。基数保留 min/max 的可选性，显示 1、0..1、0..N 等，不把所有关系补成 1:1；未知基数不显示。证明角色不显示自己的业务发生时间。属性仍属于对象，不成为独立节点。
- 普通关联为无箭头实线，跨业务边界为无箭头虚线；仅 plays_role 为虚线箭头。precedes 保留模型语义，但在主图按普通关联绘制，不显示“先于”文字或方向。跨边界按合同／领域归属独立计算，不把同一合同下的履约分组当作跨合同。
- 关系业务名称和种类保留在悬停、键盘辅助标签及详情中，不常驻在线条上。外部玩家保持实际归属；全部关系清单收入默认折叠的“查看关系详情”，平行关系不合并丢失。不在图内显示对象／关系统计、外部对象归属文字或长篇说明。
- 支持简化／标准图、缩放、适合宽度、原始大小与局部滚动。节点、责任角标和关系支持键盘，点击进入既有详情，返回保留阅读状态。
- SVG 使用 DOM 创建和 textContent，不引入图形库或网络请求。异常归属在关系详情中提示，悬空关系保留在清单，不静默修补 FM。测试覆盖单图完整覆盖、上下文边界完整性、几何包含与真实归属一致、空上下文、边界导航、实际端点、合同主线、共享确认、责任角标、玩家归属、关系线型、基数、环、悬空关系、自引用、平行关系、空输入和输入不变性；浏览器与截图核对实际可读性。

### 图形图例

画布外提供原生可折叠图例，默认收起以保留主图空间；按业务对象、上下文边界和关系连线分组。简化／标准切换称为“显示模式”，不与图例混称。展开、收起和切换模式不创建导航历史，模式切换保留展开状态。

图例采用矩形凭证、圆角参与者与普通角色、矩形凭证角色、右上责任角标，以及名称／类型／已有时间字段的居中排布。颜色与主图共享定义，不额外建立一套符号。每类只取当前模型的一个真实示例；未出现的类型或线型不展示，空模型显示空态。履约边界示例保留真实父上下文名称，不把 Context 画成业务对象。

实线、跨边界虚线和扮演箭头分别解释；箭头从实际玩家指向角色，只取真实关系端点。凭证角色不补责任方、发生时间或另一份确认。图例是说明样本，不添加主图节点、虚拟业务 ID 或业务关系；不嵌入参考材料的图片、文字或业务对象。参考材料的排布方式不能覆盖当前模型事实及已确认的主图线型规则。

测试覆盖类型集合、真实示例与责任引用、颜色一致性、线型及端点方向、空输入、键盘展开、模式切换、窄屏与单画布不变。

### 悬停与键盘高亮

- 业务对象采用“当前对象 + 一跳关联”：加粗当前对象，强调直接相连的线和另一端对象；不沿邻居继续扩散。所属上下文及祖先边界轻微强调，其他对象与线淡化但不隐藏。孤立对象仅强调自身。
- 上下文强调自身边界、真实归属的内部对象（含子上下文）及两端都在内部的连线；跨边界线和外部端点不扩展高亮。背景命中最内层边界，具体对象、责任角标与连线优先于背景。
- 责任角标按对应角色的一跳关联处理；连线悬停强调该线及两端对象。一跳只使用已绘制的正式关系和显式合同责任线，不从角标推导新连线。
- 键盘焦点使用相同规则，并优先于鼠标经过；失焦回到当前鼠标目标，没有目标时清除高亮。鼠标按下切回指针交互。临时高亮不切换详情、写入历史或展开导航；激活链接后的失焦不能留下旧高亮。
- 高亮不修改位置、实／虚线、箭头或基数。简化与标准图规则一致；测试覆盖所有对象、边界、角标、连线以及真实鼠标命中、Tab 焦点优先和恢复，截图核对淡化后的可读性。

## 对象详情

| 对象                          | 展示内容                                                        |
| ----------------------------- | --------------------------------------------------------------- |
| Evidence / Participant / Role | 所属上下文、业务属性；保留名称与 ID，不追加说明、徽标或引用区块 |
| Attribute（所属对象内）       | 名称、含义、类型、必填、关键数据；选中时只高亮并聚焦属性行      |
| Rule                          | description 业务解释、事实绑定、CEL、结果引用及使用者           |
| Relationship                  | 起点、终点、业务名称、种类和明确声明的两端基数                  |
| Scenario                      | 固定 asOf、角色步骤、可见凭证、预期与实际、履约状态及业务时间   |
| Instance                      | 凭证类型、实例值、已有凭证依赖；不混用不同场景派生结果          |
| API capability                | HTTP 方法和 URI、角色、作用对象、规则与绑定、字段和响应         |
| Resource / Representation     | 业务对象或父资源、响应字段到业务属性的映射                      |
| Journey                       | 明确的 HTTP 步骤和预期状态；标注静态设计                        |

不使用完整 JSON 作为业务详情的替代品。业务说明优先，公式其次。未声明的业务结构显示空态，不根据常识补齐。

### 业务对象双区块

凭证、参与者和角色采用两个正文区块：所属上下文与业务属性。所属上下文取真实父级上下文；独立参与者显示未声明归属，不虚构外层边界。所属上下文链接及面包屑只定位展开对应折叠组，不替换正文、不新增历史记录。Context 本身仅是结构容器，不进入此详情渲染。空属性保留区块并显示空态。属性跳转保留稳定 ID、选中高亮、焦点及返回位置，不展开附加的属性引用。

请求、确认、证明角色和玩家在整体图中表达。正文不追加说明、类型徽标、直属对象、履约证明、规则或双向引用区块；规则、场景和 API 的专用详情不受此限制。

### 引用导航

所有连线来自明确字段。相同引用去重；反向引用从正向边计算，不维护第二份关系。未知目标明确标记为未解析，不创建虚构业务对象。正式 FM/API 校验失败仍禁止发布成功工作台；展示引用诊断不能替代正式校验。

规则、关系、场景和 API 专用详情的局部关系区分“依赖与关联”和“被谁使用”。箭头或分组只是阅读辅助，不把引用顺序当作业务执行顺序。

## 视觉与交互

使用深色顶栏、浅色业务内容、清晰留白和稳定主区。Evidence、Participant、Role 的类型强调分别使用 `#b43656`、`#3d7553`、`#8d6200`，同时保留文字，不仅靠颜色识别。

- 树节点选中高亮；折叠和展开不改变业务对象。
- Ctrl/Cmd+K 聚焦搜索；Escape 清除搜索；按钮可键盘操作。
- 面包屑中的上下文定位对应折叠组，其他对象链接打开详情；返回恢复前一个对象；复制失败时显示可手工复制的 ID。
- 宽屏使用侧栏与主区，窄屏将可滚动导航置于内容上方。表格局部滚动，页面不横向溢出。
- 所有表格的表头、单元格及其中的链接文字水平居中，单元格内容垂直居中；保留换行、属性定位和按钮操作。浏览器验证全部详情表格、不同高度的同一行内容、节点两种图例及窄屏居中，不改变导航和正文段落的对齐。
- 所有状态只保存在本页内存，不使用持久化存储，不建立隐藏业务状态。

## 安全与验收

业务文本使用 DOM textContent；不使用 innerHTML、eval 或动态脚本。JSON 注入转义 HTML 结束标签，CSP 对最终内联脚本计算哈希，不允许外联。

生成器回归覆盖白名单投影、外部证明、合同计数、双向引用、悬空引用、反例、转义、CSP、输入变化和发布保护。隔离安装回归证明不依赖仓库布局、不修改输入或安装包。浏览器回归遍历全部对象与属性定位，检查三组导航及 API 子组、默认条目唯一、辅助对象不入主导航但均可搜索，关系从连线进入，场景凭证及 API 辅助对象从专用详情进入、独立对象／空态／环形归属、业务对象仅两个正文区块、属性数量与空态、同名属性归属、规则/API 引用穿透、上下文搜索／引用／图边界定位、空上下文与原生折叠交互、不创建上下文详情或历史条目、返回恢复、键盘焦点及窄屏定位，并检查实际交互和截图；断言对象存在不能替代内容可读性评审。
