# Evidence 离线业务工作台

使用本包生成器把当前业务源投影为单个只读页面，保留业务 ID 与正式引用。生成工具留在安装包，项目只接收产物。

## Guides

确定讨论、只读检查、页面生成或工具维护。讨论与只读检查不写项目文件；生成仅授权更新 `.evidence/views/index.html`；工具源码修改另需维护授权。输入是当前 `.evidence/fm/` 与可选 `.evidence/api/api.json`。

| 当前动作                         | 必要参考                                                  |
| -------------------------------- | --------------------------------------------------------- |
| 环境准备、执行失败或页面加载故障 | [运行说明](references/operations.md)                      |
| 实现维护或视觉评审               | [展示契约](references/visual-review.md)，再定位源码与测试 |

普通重新生成无需加载完整 UI 规范。联合审核必须有 API；独立 FM 可视化允许没有 API，已有 API 仍参与检查。

页面仅承载白名单业务投影，原始文件、路径、访谈、材料来源、命令、输入摘要与 Git 历史留在页面之外。业务定义与场景仍须按项目权限保管，不上传、部署或发送业务 API 请求。

## Action

1. **核对输入与环境。** 定位本包、FM 包和项目的实际绝对路径，确认 Python、依赖、浏览器及当前生成权限。联合模式核对 API 存在；只读请求只报告。完成时，运行路径、模式与允许产物明确，必要缺口已交接。
2. **生成当前投影。** 使用下列命令；联合审核增加 `--require-api`。生成器检查 FM 后将同一结果交给同包 API 自身校验，核对两源与场景新鲜度，仅原子替换自己拥有的页面。完成时，生成实际成功且输入未变，正式源与 generated 目录保持不变。

   ```bash
   "$PYTHON" -B "$VISUAL_SKILL_DIR/scripts/generate.py" \
     --project-root "$PROJECT_ROOT" \
     --fm-skill "$FM_SKILL_DIR"
   ```

3. **验证最终页面。** 按 Sensors 对落盘 HTML 执行浏览器回归并检查截图；专项命令与覆盖见运行说明。完成时，对象、引用、交互与可读性有实际证据，或缺少环境及未执行项明确可见，不能把未验证页面当成完整交付。

## Sensors

```bash
node "$VISUAL_SKILL_DIR/tests/review-browser.mjs" "$PROJECT_ROOT/.evidence/views/index.html"
```

非默认浏览器用 `CHROME_BIN` 指定。核对真实日志、HTML 摘要与截图：对象／引用完整，交互可读，无脚本错误或外部请求，检查期间文件未变。无适用场景或 API 时说明不适用；缺少环境时说明未执行。

机器校验、页面检查、业务批准与运行时接口验证分别报告。浏览器断言不能替代截图可读性评审，文件存在不能证明当前输入有效。

## Steer

- **源检查失败或输入变化**：停止并保留旧页，明示它不是当前有效证据；输入稳定后重新生成。
- **输出归属、环境或权限不满足**：停止并交接，不自动覆盖、安装或删除。
- **页面故障**：按运行说明定位问题，保持 FM/API 只读；保留 CSP，不手改或格式化生成 HTML。获授权工具修复后重新生成并复验。
- **完成**：报告 HTML 路径、实际检查、未执行项及绝对路径重生成命令后停止。页面是快照，不是批准或计划状态；业务来源、历史证据与 Git 保持不变。
