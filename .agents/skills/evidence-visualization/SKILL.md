# 业务对象工作台

把业务模型变成可以逐层阅读的对象空间：业务边界 → 责任与凭证 → 规则与场景 → 接口能力。业务对象只阅读所属上下文和业务属性；关系、规则、场景与接口由各自入口阅读，不要求读者先理解全局关系图。

## 边界

- 只讨论时给建议；只检查时报告结果。只有要求生成或更新时才写 `.evidence/views/index.html`。
- 使用本 Skill 的生成器，不向业务项目复制工具实现。读取当前 `.evidence/fm/` 与可选 `.evidence/api/api.json`；不修改它们、业务材料、历史检查记录或计划状态。
- 页面只承载白名单业务投影，不嵌入原始文件、文件路径、访谈、来源记录、引用依据、执行命令、输入摘要或 Git 历史。不复制外部参考项目说明。
- 业务对象 ID、属性引用、角色扮演和凭证依赖属于模型语义，必须保留；它们不是材料来源信息。
- 不补造合同、确认凭证、权限、审批流或业务界面。责任角色不等于系统授权，HTTP 静态设计不等于运行实现。
- 页面仍含业务定义和合成场景数据，不因此视为匿名数据；不上传、不部署、不发送业务 API 请求。

## 生成

先定位本 Skill、FM Skill 和需要时的 API Skill 的真实安装路径；项目根与安装目录独立。依赖缺失时说明限制，不自动安装软件。

```bash
"$PYTHON" -B "$VISUAL_SKILL_DIR/scripts/generate.py" \
  --project-root "$PROJECT_ROOT" \
  --fm-skill "$FM_SKILL_DIR" \
  --api-skill "$API_SKILL_DIR"
```

没有 API 可以省略 `--api-skill`。没有显式参数时只尝试项目 `.agents/skills/` 下的同名包。

生成器重新运行正式 FM 检查、编译与适用场景模拟；已有 API 时调用其正式投影 CLI。临时产物自动清理，生成前后和发布前核对输入是否变化；校验失败或输入变化不覆盖已有工作台。只原子替换本生成器拥有的文件，遇到其他 HTML 不自动覆盖。

## 阅读与语义

详细展示约定见 [工作台设计](references/visual-review.md)。实现维护或视觉评审时读取；环境、命令及故障处理见 [运行说明](references/operations.md)。

- 首页是一张完整全局模型图，直接展示所有凭证、参与者、角色与正式关系，不汇总为边界卡片、不切换合同、不折叠外部玩家。按合同—请求—确认／证明组织位置；同一画布用有名称的边界框区分领域、合同与履约上下文，履约嵌套在所属合同内。边界来自真实归属，不是流程泳道。不显示列标题、图内统计和长篇说明。共享确认及外部玩家只画一次，保留原归属；不补造确认。属性、规则、场景实例和 API 不成为主图节点；Context 作为边界而非关系端点，点击或键盘激活边界名称只定位并展开左侧对应上下文分组，不打开详情。
- 简化图显示名称和已有责任角标；标准图增加已有类型、时间字段及真实基数。普通关联不画箭头，跨业务边界用虚线，仅角色扮演用虚线箭头；precedes 在图上退为普通关联，不显示“先于”标注，其语义留在关系详情。跨边界与关系类型独立计算。关系名称通过悬停及详情查看，完整清单默认折叠。支持缩放、原始大小、局部滚动、键盘及详情返回。
- 图例是画布外可展开的图形说明，分业务对象、上下文边界、关系连线；图形、颜色、责任角标和箭头与主图一致，每项配当前模型中的真实示例，未出现的类型不展示。参考材料只指导形式，不引入其业务对象；图例样本不成为第二张模型图。简化／标准的切换标为“显示模式”。
- 悬停对象高亮自身、一跳连线与邻居，所属边界轻微强调，其余淡化；悬停上下文只强调内部对象与内部线，嵌套时命中最内层。责任角标按对应角色处理，键盘焦点优先于悬停，移出／失焦恢复；不改变详情、历史、折叠状态或关系语义。具体规则见工作台设计。
- 左侧固定为业务结构、验证场景、API 三组。业务结构用折叠分组承载 Context，每个上下文只有一个分组标题，不再列重复对象条目，也没有独立详情或属性面板；空上下文仍保留折叠组。组内展示凭证、参与者、角色和规则，独立参与者放在同组；API 下分接口能力、接口资源、调用流程。场景凭证从场景详情进入，响应表示和实例绑定从接口详情进入，业务关系从图上连线或搜索进入，不单开导航栏目。空组显示空态，不补造内容。
- 全局搜索覆盖全部对象，包括关系、场景凭证、响应表示、实例绑定与属性；收起导航入口不删除数据、ID 或引用。属性在所属对象详情中展示，搜索结果标明所属对象名称和 ID，引用跳转定位并高亮属性，返回恢复该定位。
- 凭证、参与者和角色的详情保留名称与 ID，正文固定为所属上下文、业务属性两个区块；无归属或无属性显示空态。所属上下文、面包屑及上下文搜索命中只定位展开对应分组，保持当前正文、历史和画布状态；属性保留类型、必填、含义和关键数据；选中属性只高亮定位，不追加引用面板。支持面包屑、返回和复制 ID。
- 规则、关系、场景、场景凭证和 API 保留各自专用详情及显式正反向引用。图上保留请求、确认、证明角色及实际玩家，外部玩家不移入消费合同；业务对象详情不另设完成证明或局部关系面板。
- 场景显示固定 asOf、推演步骤、当时可见凭证、规则预期与实际、履约结果及业务时间。false 可以是正确反例；步骤顺序不代表真实时长，未确定顺序不推断。
- API 能力显示调用角色、作用对象、规则、绑定、字段、响应和静态调用流程。仅有角色声明不能证明访问控制。
- 合同边界只统计 Contract Context，不把 Contract Evidence 再计一次；业务对象计数只含凭证、参与者与角色，不含上下文容器。机器检查、业务批准和运行验证分别表达。

## 验证与交接

对最终落盘文件执行：

```bash
node "$VISUAL_SKILL_DIR/tests/review-browser.mjs" "$PROJECT_ROOT/.evidence/views/index.html"
```

使用 `CHROME_BIN` 指定非默认浏览器。测试单张画布完整覆盖、全部上下文边界及真实归属包含关系、空上下文、边界名称导航、真实端点、无先于箭头或多余标注、合同主线、责任角标、共享确认与玩家不复制、简化／标准图、真实时间字段与基数、缩放、键盘与详情导航，以及三组导航、无重复条目、独立对象／环形归属／空态、业务对象双区块及空态、属性定位不追加区块、辅助对象搜索与详情入口、专用详情引用、上下文定位不切换正文或新增历史、图上外部证明、规则说明、场景反例、窄屏和文本安全；检查脚本错误、外部请求与文件未变，并查看截图。无适用场景或 API 时说明不适用；缺少环境不得声称验证通过。

提供 HTML 路径、实际检查结果、未执行项和使用实际绝对路径的重生成命令后停止。离线工作台是快照，修改业务输入后需要重新生成。不要手改或格式化生成 HTML，也不要通过关闭 CSP 修复加载失败。
