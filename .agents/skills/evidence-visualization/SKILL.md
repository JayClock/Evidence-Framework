# Evidence 离线业务工作台

使用本包生成器把当前业务源投影为单个只读页面，保留业务 ID 与正式引用。生成工具留在安装包，项目只接收产物。

## Guides

确定讨论、只读检查、页面生成或工具维护。讨论与只读检查不写项目文件；生成仅授权更新 `.evidence/views/index.html`；工具源码修改另需维护授权。输入是当前 `.evidence/fm/` 与可选 `.evidence/api/api.json`。

| 当前动作                         | 必要参考                                     |
| -------------------------------- | -------------------------------------------- |
| 环境准备、执行失败或页面加载故障 | [运行说明](references/operations.md)         |
| 实现维护或视觉评审               | [展示契约](references/visual-review.md)，再定位源码与测试 |

普通重新生成无需加载完整 UI 规范。没有 API 的独立 FM 页面不需要 API 包或 `--api-skill`。联合审核必须有 API；独立 FM 可视化允许没有 API，已有 API 仍参与检查。

页面只承载白名单业务投影：原始文件、路径、访谈原文、材料来源、命令、输入摘要与 Git 历史留在页面之外。业务定义与场景仍须按项目权限保管，不上传、部署或发送业务 API 请求。

**红线（不可协商）**

- 页面只读：不修改 FM、API、`generated/` 或任何业务源。
- 联合审核必须有当前 API；缺 API 时不降级为独立 FM 页面。
- 生成失败或输入变化时保留现有页面作为历史快照，不覆盖目标文件；输入稳定后方可重新生成。
- 页面上的金额、期限、数量、时间差必须与其派生规则或结果事实一致；不补造凭证或默认值。

## Action

1. **核对输入与环境。** 定位本包、FM 包、适用的 API 包和项目的实际绝对路径，确认 Python、依赖、浏览器及当前生成权限。联合模式核对 API 存在；只读请求只报告。完成时，运行路径、模式与允许产物明确，必要缺口已交接。

2. **生成当前投影。** 使用下列命令；联合审核增加 `--require-api --scope "$CONTEXT_ID"`，可重复 `--scope` 覆盖 API 实际范围及必要依赖。生成器检查 FM 后将同一结果交给模型内的 API 投影，核对两源与场景新鲜度，仅原子替换自己拥有的页面。完成时，生成实际成功且输入未变，正式源与 generated 目录保持不变。

```bash
npx evidence-workbench generate --project-root "$PROJECT_ROOT"
# 联合审核：追加 --require-api --scope "$CONTEXT_ID"（可重复）
```

生成器是 TypeScript（`libs/evidence-visualization`），在进程内完成检查、投影、渲染与发布，无需 Python 解释器。`scripts/generate.py` 保留为参考实现，输出与之一致，仅供对照与回归。

3. **验证最终页面。** 按 Sensors 对落盘 HTML 执行浏览器回归并检查截图，同时核对关键数据展示：属性详情是否给出派生规则或结果事实，追溯问答是否与模型一致。完成时，对象、引用、交互、关键数据与可读性有实际证据，或缺少环境及未执行项明确可见。

## Sensors

运行自动化测试套件核验页面质量，分级管理反馈信号：

```bash
node "$VISUAL_SKILL_DIR/tests/review-browser.mjs" "$PROJECT_ROOT/.evidence/views/index.html"
```

非默认浏览器用 `CHROME_BIN` 指定。

**阻塞级**：生成脚本失败；HTML 替换失败；浏览器回归报错（脚本异常、CSP 违规、外部请求）；页面存在未解析的悬空引用；关键数据（金额/期限/数量/时间差）未绑定规则说明或结果事实且未标识缺口。任一出现立即停止交付。

**警告级**：复杂领域规则超出模拟器渲染能力（列入模拟限制）；单 FM 模式缺少 API 投影时按空态展示；窄屏布局微调项。

**信息级**：渲染对象数、HTML SHA-256 摘要、生成耗时、截图输出路径。

核查维度：
- **对象与引用**：对象数、引用完整、无悬空链接。
- **关键数据**：金额、期限、数量、时间差在详情中能定位到规则说明或结果事实；没有规则又不属结果事实的项列为缺口，不在页面补值。
- **交互与移动端**：检索、选中、图例、上下文框与窄屏布局可用。
- **安全与发布**：无脚本错误、无外部请求、检查期间文件未变、页面不含源文件路径。
- **证据限制**：图示包含当前完整 FM，一致性、范围完整性、派生图与场景结果分别展示；模拟器不能执行的领域行为明确列为限制。

自动化回归断言通过后，结合临时目录中的无头浏览器截图人工核对布局与文本可读性。

## Steer

- **源检查失败或输入变化**：保留旧页作为历史快照，不覆盖目标文件；输入稳定后重新生成。
- **关键数据展示不一致**：以 FM 为准，页面不补值；规则缺失时交回 `evidence-fm` 补台账与规则，再重新生成。
- **输出归属、环境或权限不满足**：停止并交接，不自动覆盖、安装或删除。
- **页面故障**：按运行说明定位问题，保持两源只读；保留 CSP，不手改或格式化生成 HTML。获授权工具修复后重新生成并复验。
- **完成**：报告 HTML 路径、实际检查项及绝对路径重生成命令后停止。业务来源、历史证据与 Git 保持不变。
