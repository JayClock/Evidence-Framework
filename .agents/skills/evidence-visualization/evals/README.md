# 当前工作台行为评测

[案例](evals.json)检查现行生成器的投影与交互，不重新实施已经交付的图形或导航重构。`contract_refs` 指向当前[入口](../SKILL.md)、[运行方法](../references/operations.md)和[展示契约](../references/visual-review.md)；展示契约改变时同步核对案例，而不是保留旧实现任务。

## 隔离输入与执行

使用独立临时项目、新会话及当前安装的FM／Visualization包。按题面准备最小合成模型及适用API；可复制实际FM包的表达样例，再在隔离副本中准备场景。多合同、共享确认、外部玩家、空态或歧义规则必须由真实合法结构表达，不把材料名称或提示文字当测试夹具。

先由当前FM及API检查器确认正向输入有效；失败案例则保留可复验的原始错误及旧页。记录安装包和输入文件的前后摘要、源版本、浏览器环境及权限。只向待评Agent提供题面与来源，不提供expected_output作为答案。

Agent仅调用当前生成器更新隔离项目页面，再检查最终HTML、浏览器断言与截图；不修改生成器、安装包样例、FM、API或generated。缺少浏览器、依赖或合法输入时说明未执行或阻塞，不重写工具制造成功。

## 判定

按category及expected_output逐项核对：联合或纯领域投影、失败不发布、业务结果与预期匹配、完整单图及真实归属、辅助对象可达、普通对象及字段详情、上下文定位、一跳高亮及焦点恢复、真实图例、Request条件与证明。

页面存在或节点计数不能替代实际内容、引用、交互与截图检查。来源隐私检查覆盖落盘HTML的全部白名单数据，不只观察可见文字；输入不变性同时检查项目源与安装包。静态测试与真实Agent执行分别报告，未执行保持未执行，不记录虚构通过率或业务批准。
