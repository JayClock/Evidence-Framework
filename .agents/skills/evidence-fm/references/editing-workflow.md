# 正式编辑执行路径

本页固定编辑与检查的顺序，不主持访谈，不保存第二套准入状态。实际业务判断由对应专业方法维护；合同级准入覆盖当前合同的完整责任，不能以其中某项履约的编辑切片替代。仅讨论、术语沉淀、API-only 和只读校验不进入本图的 FM 编辑路径，按入口对应分支执行。

## 路径与出口

```mermaid
flowchart TD
    input[读取本轮权限、当前来源、模型与差异]
    admission{合同级或相应范围人类追责结束依据有效，且有编辑授权}
    mapping[复核业务分析，映射已确认依据]
    edit[直接编辑当前模型、说明与获授权术语引用]
    difference[核对实际增改删、引用闭合与事实忠实性]
    check[适用词汇检查与一次 FM 检查]
    valid{退出成功、valid 为 true、inputChanged 为 false}
    narrow{明确仅 FM}
    api[整体 API 设计、API 自身检查与投影；消费同一 FM 结果]
    apiValid{获授权 API 交付完整且输入未变}
    blocked[交接缺口、保存结果与未执行阶段后停止]
    handoff[交接本轮实际结果后停止或返回组合入口]
    input --> admission
    admission -->|不满足或失效| blocked
    admission -->|满足| mapping
    mapping --> edit
    edit --> difference
    difference --> check
    check --> valid
    valid -->|失败、失配或输入变化| blocked
    valid -->|通过| narrow
    narrow -->|是| handoff
    narrow -->|否| api
    api --> apiValid
    apiValid -->|失败或缺口| blocked
    apiValid -->|通过| handoff
```

图中的技术表达错误只在当前授权内修正并复验，不能改业务预期来通过。新责任或来源冲突交回依据拥有者，不自动解除访谈停止／暂缓；保存失败保留各文件实际结果，不自动回滚。

## 每步前馈与反馈

| 步骤    | 必要前馈                                                                                                      | 可观察反馈与转向                                                                                |
| ------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 准入    | [全部追责结束](responsibility-closure.md)规定的合同级或相应范围、完整责任图、人类终点及结束确认，当前编辑授权 | 依据覆盖当前版本；任何必要分支未闭合即停止，纯领域也按该方法判断                                |
| 映射    | [批次评估](batch-assessment.md)与业务分析，当前正式对象及来源                                                 | 对象、属性、关系、规则、场景和稳定 ID 可定位；未澄清合同使用 Context Role，不以假凭证补齐       |
| 编辑    | [语义](semantics.md)、[格式](format.md)及当次所需时间、CEL、场景方法                                          | 只维护授权对象；删除清理引用，术语保留 term ID 并改为 FM 引用，定义归目标唯一维护               |
| 差异    | 已有 Git 改动、未跟踪新文件与本轮目标                                                                         | 已有与本轮变化分开，支撑引用闭合，实际 JSON 忠实于已确认事实，不手改 generated                  |
| FM 检查 | [检查纪律](validation.md)，当前词汇、完整模型和适用场景                                                       | 退出码与内容均有效，modelDigest 匹配；未执行场景的 simulationPassed 为 null，输入变化使结果无效 |
| API     | [API 阶段](api-design.md)，整体模型与同一次有效 FM 结果                                                       | --fm-check 消费该结果并核对摘要，不重复 FM 检查或模拟；缺口交接，失配返回 FM 阶段               |
| 交接    | 当前差异、各文件结果、实际检查与未覆盖能力                                                                    | 来源映射、增改删、命令、输入摘要及未执行限制可定位；独立调用不自动生成页面或下游                |

## 选择表达样例

从 [正式表达基线](../examples/README.md) 只读当前判断需要的样例：订阅付款用于关键值与时间，领域档案用于无合同对象，结构对照用于上下文和证明，商品采购用于整体 API。样例只固定表达模式，不能提供当前业务事实、期限、权限或人类确认。

取得准入依据不等于批准生成后模型；编辑授权不是业务批准。FM 与 API 的保存不是原子事务，后续失败不撤销已保存 FM，也不宣称完整交付。来自组合入口时交回已获授权后续阶段及合同级未澄清项，由入口接续 Handoff；独立调用完成后停止。
