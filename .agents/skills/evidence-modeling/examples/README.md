# 分派与交接基线

这些合成样例约束授权裁剪、阶段顺序和交接表达，不替代实际来源、专业检查或人类准入依据。示例结果不是当前项目已执行的结果，不复制摘要、退出码或保存结论。

| 当前动作                         | 按需读取                           | 重点                                                   |
| -------------------------------- | ---------------------------------- | ------------------------------------------------------ |
| 首次选择生成、仅 FM 或只读分支   | [权限与步骤对照](permissions.json) | 更窄授权先裁剪，API 消费同一 FM 结果                   |
| 完成交接、阶段阻塞或恢复部分交付 | [交接正反例](handoffs.md)          | 合同级建模后保存未澄清部分；已保存与未完成分开，不回滚 |

日常访谈沿 Discovery 的当前动作加载其样例，不读取本页来重新分派。专业映射与模型结构读取 FM 的方法和样例；本包只判断谁执行、允许写什么、实际交付到哪一步。

[交接模板](../assets/handoff-template.md)只约束临时报告，不新增业务记录或状态文件。维护检查覆盖图的分支、样例权限和文件归属；真实执行仍需隔离会话记录命令、文件差异与停止位置。
