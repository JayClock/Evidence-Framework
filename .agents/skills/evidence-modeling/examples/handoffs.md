# 交接正反例

以下都是合成执行情形，不代表实际命令或人类批准。报告只填写真实观察，路径沿用当前项目指定位置；专业依据引用原记录，不复制业务正文。

## 1. 完整生成：每个阶段分别有证据

**输入**：已授权完整生成，FM 核对当前全部追责结束依据后编辑并检查；整体 API 检查、投影与联合页面的浏览器检查均实际完成。

**交接**：列出两源与页面的实际差异、各文件保存结果、实际命令和摘要指针。说明 API 阶段复用 FM 检查结果；独立页面运行重新检查两源，API 仍消费该次结果。场景未运行则写未执行，不用页面截图代替业务模拟；静态 API 交付不声称真实服务已运行。

**反例**：“模型文件都在，整条链路完成。”文件存在不能替代阶段检查，也不能把机器通过当成业务批准。

## 2. 仅 FM：到授权终点就停

**输入**：“只修改 FM，不设计 API，不生成页面。”

**交接**：只列获授权 FM 与适用术语变化、当前 FM 检查、表达限制及未决影响。明确 API 与页面未执行，完成本轮后停止。

**反例**：“为方便审核，顺手更新了 API 和页面。”便利性不扩大权限。默认完整链路已经被更窄要求裁剪，不再索取已获得的 FM 编辑授权，也不擅自追问业务。

## 3. 只校验：报告不落盘

**输入**：“只校验当前 FM 与已有 API，不写任何项目文件。”

**交接**：使用项目外临时 FM 检查结果，API check 消费同一结果。分别报告两源结果和未覆盖限制，不执行 project、不保存项目报告、不修复源、不生成页面；输入变化时结果失效。

**反例**：“校验失败，已自动修复并生成新页。”检查请求不是修复授权。API 缺失只能交接联合检查未完成，不能生成空 API 或降级页面。

## 4. API 阻塞：部分交付不是全交付

**输入**：完整生成已授权。FM 已保存并检查通过，整体 API 设计时发现某能力的必要角色权限尚无依据；本情形尚未保存 API 源。

**期望交接**：

```text
FM 与适用词汇更新已保存，当前 FM 检查已通过。
API 的角色权限依据仍缺失，API 源未保存，投影与联合审核未执行。
缺口交回业务依据拥有者；不反向修改 FM，不自动恢复访谈。
已有页面保留，但不代表本次两源的有效联合结果。本轮停止。
```

实际若已保存部分 API，则列明该文件真实结果，不能照抄“未保存”。使用检查记录指针交接命令、摘要与覆盖，不在日常故事里添加材料路径。

**反例**：“已交付模型和 API”“撤销模型等待全部成功”“先生成没有 API 的联合页”。它们分别掩盖未完成阶段、自动回滚已保存源、绕过严格联合检查。

## 5. 必要运行依赖缺失：在受影响写入前停

完整生成前发现 FM 或 Visualization 专业包、必要运行依赖不可用，交接资源限制与未执行阶段，不先改模型，不让用户用业务回答弥补环境。可选交互界面缺失不属于专业依赖缺失，普通对话可继续获授权分支。
