# 本轮交接

这是临时报告模板，不新增业务记录、状态文件或模型批准字段。只列实际结果与稳定指针；没有变化或不适用的项省略，未执行与未保存明确说明。模板中的标题不是访谈日常故事格式。

## 授权

本轮分支、允许写入及限制；实际增改删与已有无关改动分开。

## 输入与恢复

输入版本及来源定位、当前对象引用、原问题及各题已答／未答／暂缓情况与控制意图；不复制事实、词汇定义或故事。

## 文件结果

各文件分别列已保存、未保存或未修改；保存失败保留错误及未保存内容，不宣称原子事务。

## 检查

实际命令、退出码、输入摘要和记录指针、覆盖及未执行项。FM 与 API 分别说明，API 是否复用 FM 结果可定位；独立页面运行的检查不混成设计阶段重复校验。机器通过不表示业务批准。

## 剩余工作

具体对象、缺口、未完成阶段及接收方；旧页面或历史检查的适用限制单独说明。合同级接续列明未澄清合同、实际 Context Role ID、原问题、暂缓意图与恢复位置，引用 evidence-handoff 实际保存的 Markdown 路径；保存失败明确列出未保存内容，不用本临时报告冒充已保存交接。

## 停止

本轮结束或阻塞后停止。下一步建议不是授权，不自动恢复访谈、生成下游或操作 Git。
