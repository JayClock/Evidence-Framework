# 建模过程交接

整理当前建模过程，让新的会话能接着工作。用户给出的参数表示下一轮重点，据此选择需要保留的内容。

## 整理

依据当前会话中的实际讨论和可读取产物，压缩为：

- **目标与权限**：本轮业务范围、用户要求及允许的动作。
- **分析进展**：已识别合同与经营依据、全部主履约、当前请求—确认骨架、关键数据追溯，以及已展开的异常责任；领域或协商按实际主线说明。
- **判断与决定**：重要结论、选择理由及更正影响；区分已明确事实、确定性推导、工作假设与人类决定。
- **人类确认覆盖**：范围、分支终点及全部追责结束确认分别说明其覆盖对象与业务版本；缺失或失效之处明确列出。
- **未决与控制意图**：当前问题、依赖、暂缓项、冲突，以及停止或继续的意图。
- **当前产物与验证**：引用词汇表、FM/API、场景、检查结果等实际路径，说明真实保存与执行结果。
- **下一轮焦点与建议 Skills**：指出承接位置、仍需核对的依据和一个合理的起点，列出适用 Skill 名称。

已有产物通过路径或 URL 引用，正文保留继续工作所需的摘要。敏感值脱敏，凭据使用占位说明。上下文缺失、未保存或未执行的内容按实际情况标明。

## 保存

沿用用户指定路径。未指定时，以业务主题选一个可辨认的文件名，保存到 `.evidence/handoffs/<主题>.md`。写入前核对目标文件；已有文件按本轮授权更新或选择新名称，保留其他内容。

保存成功后返回文件路径及下一轮使用方式：读取该文档与其中引用的实际产物，按推荐 Skill 核对当前目标、控制意图及确认适用性后继续。写入失败时说明错误，提供尚未保存的交接内容。
