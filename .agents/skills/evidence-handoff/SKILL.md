# 建模过程交接

让新的会话接着工作，而不是重读全部对话。交接保留继续判断所需的摘要，已有产物用路径或 URL 引用。

## Guides

读取显式请求或建模入口传递的合同级自动交接、领域／协商分支自动交接授权、当前讨论与可查产物，确定下一轮焦点及写入权限。只读、只聊不落盘或不保存交接等明确限制优先，不从普通访谈或停止意图自行触发保存。用户参数表示下一轮重点；未指定路径时保存到 `.evidence/handoffs/<主题>.md`。写入前核对目标文件，已有内容按授权更新或另选名称。

按项目的领域语言方法核对交接中的业务概念，使用当前上下文的规范名称；若采用 Evidence 词汇入口，通过资源发现定位 FM 包的 `references/domain-language.md`。已有词汇条目只读取和引用，不另抄定义，不把未保存的术语建议写成已有定论。

## Action

1. **定位承接点。** 确定当前范围、允许动作、上下文类型、合同／履约／请求或确认，或领域对象／规则、协商方案／回应、原问题与控制意图。围绕下一轮重点选择必要信息，关键上下文不足时明示限制。完成时，能指出下一轮从哪里继续、哪些动作仍需授权。
2. **压缩交接内容。** 按实际讨论组织以下摘要，已有文件只引用，不再复制全文：
   - **目标与权限**：本轮业务范围、用户要求与允许动作。
   - **分析进展**：实际约定与责任双方、当前已知主履约及新增协作、请求—确认骨架、关键数据追溯与异常责任；领域或协商按实际主线说明。领域保留复用连接范围、已采用方案及适用依据、必要能力与限制、获授权深入的部分；未展开不等于未决，不把无关内部机制变成下一轮待办，也不将复用确认写成内部实现或集成已验证。
   - **判断与决定**：结论、选择理由及更正影响；区分已明确事实、确定性推导、工作假设与人类决定。
   - **人类确认覆盖**：范围与全部主履约、分支终点、单合同结束、领域与协商的分支结束及全部追责结束确认分别说明覆盖对象及业务版本；缺失或失效之处明确列出。
   - **未决与控制意图**：当前问题组及各题原标识、已答与未答、依赖、暂缓项、冲突及停止或继续意图。
   - **未澄清合同与 Context Role**：合同级自动交接逐项保留剩余合同的已知约定、责任双方、主履约与尚未明确责任，引用实际 Context Role ID 及其消费合同、外部边界与证明约定；无业务关联或尚未创建角色时如实说明。保留原问题和回溯位置，不把角色当成内部合同已建模或结束。没有剩余合同时明确合同部分为空，仍核对其他未澄清上下文。
   - **未澄清上下文及关联**：保留领域对象／规则、协商方案／回应的边界、依据、当前问题和恢复位置，以及与合同责任的关联和影响；不因领域归类删除原合同责任，不把领域对象当作实际责任主体。只引用真实存在的对象与角色 ID，不为交接补造模型。所有类型均无剩余项时才说明未澄清部分为空。
   - **当前产物与验证**：词汇表、FM/API、场景、检查等实际路径与真实保存与执行结果；未保存或未执行内容明确标明。
   - **下一轮焦点与建议 Skills**：承接位置、待核对依据、一个合理起点及适用 Skill 名称。

   完成时，新会话能找到实际依据，并区分事实、假设、决定和待办；敏感值脱敏，凭据只留占位说明。

3. **保存并返回。** 将 Markdown 写入指定或默认路径，保留已有无关内容。完成时，工具确认保存成功，实际路径与下一轮使用方式已返回；写入失败则交接错误和尚未保存内容。

## Sensors

交接前核对：焦点与控制意图准确；规范名称与上下文一致，未保存术语未被当作定论；人类确认覆盖当前业务版本；未决依赖与暂缓项完整；引用能定位真实产物；保存与执行结果如实；敏感信息已脱敏。文档记录确认，不替人类补作确认或批准。

## Steer

- **上下文或引用缺失**：明确限制与待核对项，保留已有事实，不猜测补齐。
- **写入失败**：说明错误并提供未保存内容后停止；恢复先核对实际文件，再补齐授权内容。
- **完成**：返回实际路径和保存结果后停止；自动交接完成不自动切换上下文、解除暂缓或批准模型。下一轮读取交接及所引产物，按建议 Skill 核对当前目标、控制意图和确认适用性后继续。
