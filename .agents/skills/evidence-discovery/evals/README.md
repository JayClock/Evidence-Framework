# 访谈行为评测

[案例](evals.json)用于隔离验证访谈行为，不是日常问答参考或已执行结果。案例按独立风险保留：同一能力的单点、成组和跨会话变体合为连续案例；只复述样例、没有实际材料的结束声明或重复检查相同控制边界不单独成题。规则仍由 [访谈协议](../references/interview.md) 与 FM 方法维护。

## 隔离执行

使用独立临时项目、新会话及合成输入，提供实际 evidence-fm 安装路径和题面权限。files 相对本 evals 目录解析；当前合同发现案例直接在题面给出约定、角色、凭证及未知。题设不代表真实项目事实或业务批准。

案例 91—97 连续核对约定入口、必要前提、主要履约方向、外部凭证带出的独立约定、实际主体与代表、按需总览及凭证逆推。先核对当轮能推进的判断，再观察回答后的增量发现；不以固定选项数量或经营标签评分。

真人依次提供 follow_up，待评 Agent 不自答。跨会话提供案例中的实际理解、引用材料、原问题与控制意图；上下文不足的案例不得预先补齐缺口。对比新旧版本时固定模型、宿主、权限与输入，至少独立运行三次，保存逐轮问题、来源及依赖变化、读取轨迹、真实工具结果与停止位置。

案例 13 统一覆盖单点或成组答案的术语写入失败与增量恢复：由环境真实拒绝写入，保留错误及文件实际内容，再恢复权限；题面不能代替实际故障。案例 62 在后续回答前加入无关词汇，核对增量写入是否保留外部改动。不要把未答、局部暂缓和整轮停止混为一种状态。

## 判定与证据边界

逐条核对 expectations，报告通过、失败或未评及实际依据。重点检查完整普通对话路径、依赖前沿、每题一个判断、事实复用、部分回答后的重算、各凭证责任、停止与确认、人类范围及术语实际结果。每轮主动核对相关请求、确认及支撑凭证，寻找全部可同时澄清的独立内容，不在找到第一题后停止；局部依赖不造成整轮逐问，责任归所属合同一方。名称含义明确时直接翻译英文，不以缺英文制造业务问题；问题数量服从真实依赖，不使用固定问卷；有必要未知才问，没有可问项不代表责任闭合。

静态结构与资源测试只验证文档契约。没有实际执行就保持未执行，评测轨迹和结果存于隔离目录，不写入正式业务源或制造任务完成状态。
