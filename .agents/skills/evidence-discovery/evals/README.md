# 访谈行为评测

[案例](evals.json)检查经营依据与合同边界识别、请求—确认骨架、关键数据追溯、递归责任、参与者、单据推演、变化点、术语沉淀及控制意图。评价围绕共同理解与下一问的必要性。

## 隔离执行

使用独立临时项目、新会话及合成业务输入。专业案例提供实际 evidence-fm 安装路径；一般澄清案例按题面提供资源。新旧版本固定模型、宿主、权限与输入，至少独立运行三次。

真人依次提供 follow_up。跨会话提供题述当前理解、必要材料及控制意图；手动交接案例显式调用 evidence-handoff，再仅提供交接文档与引用产物。维护者保存原始执行轨迹与差异用于评测。

案例 35 至 40 检查经营主线与独立边界，其中 35 使用[脱敏匿名材料](fixtures/anonymized-marketplace-agreement.md)。files 相对本 evals 目录解析，材料按实际内容提供；该节选不是完整协议。

案例 41 至 44、48 检查位置、业务名称与追溯故事，正常和争议情况分别核对。案例 45 至 47、53 至 55 检查导航、已结束项、同名选择及材料不足。案例 34 检查承接上下文不足。

## 交互与失败

案例 49 不注册任何 UI 工具，验证完整普通对话路径；50 使用相同输入比较纯文本与可选 UI 的业务理解、控制意图及术语权限；51 实际撤去界面，区分不可用与取消。

案例 13、52、63 由环境真实拒绝术语写入，恢复后只补齐获授权条目。检查实际保存结果与停止位置，已收到事实直接复用。

案例 56 至 63 保留读取轨迹，检查首次与连续回答的加载差异、更正传播、全局确认、外部变化及上下文丢失。按实际可取得数据统计读取量、时间与 token。

## 判定

逐条核对 expectations，报告通过／失败／未评及依据。重点检查事实复用、前置依赖、一轮一问、真实责任覆盖、人类确认适用性、当前展示与术语归属，以及显式交接的独立授权。

静态结构与资源测试只验证文档契约。没有实际执行就保持未执行，结果存于隔离评测目录。
