# 访谈行为评测

[案例](evals.json)用于隔离验证访谈行为，不是日常问答参考或已执行结果。案例按独立风险保留：同一能力的单点、成组和跨会话变体合为连续案例；只复述样例、没有实际材料的结束声明或重复检查相同控制边界不单独成题。规则仍由 [访谈协议](../references/interview.md) 与 FM 方法维护。

## 隔离执行

使用独立临时项目、新会话及合成输入，提供实际 evidence-fm 安装路径和题面权限。files 相对本 evals 目录解析；当前合同发现案例直接在题面给出约定、角色、凭证及未知。题设不代表真实项目事实或业务批准。

案例 98—104 按现金权责与目标—实际对比核对业务发现：收款承担义务、付款取得权利、内部绩效尚无实际偏差时仍可分析、同一经营约定中的非付款义务、经营依据缺失、支付协作与代表身份、混合上下文导航及现金单据逆推。必须解释收入流、成本结构与真实责任的关系，已知依据直接承接、未知依据先澄清；不以固定选项数量或经营标签评分，不为领域或工具补造合同。

真人依次提供 follow_up，待评 Agent 不自答。跨会话提供案例中的实际理解、引用材料、原问题与控制意图；上下文不足的案例不得预先补齐缺口。对比新旧版本时固定模型、宿主、权限与输入，至少独立运行三次，保存逐轮问题、来源及依赖变化、读取轨迹、真实工具结果与停止位置。

案例 11 核对定义更正只说明当前 Entity 的待改影响，不把访谈授权当作正式编辑授权。连续问答直接消费相关模型定义，尚无模型时承接实际材料，不创建占位对象。不要把未答、局部暂缓和整轮停止混为一种状态。

## 判定与证据边界

逐条核对 expectations，报告通过、失败或未评及实际依据。重点检查完整普通对话路径、依赖前沿、每题一个判断、事实复用、部分回答后的重算、各凭证责任、停止与确认、人类范围及模型定义的待改影响。每轮主动核对相关请求、确认及支撑凭证，寻找全部可同时澄清的独立内容，不在找到第一题后停止；局部依赖不造成整轮逐问，责任归所属合同一方。名称含义明确时直接翻译英文，不以缺英文制造业务问题；问题数量服从真实依赖，不使用固定问卷；有必要未知才问，没有可问项不代表责任闭合。

静态结构与资源测试只验证文档契约。没有实际执行就保持未执行，评测轨迹和结果存于隔离目录，不写入正式业务源或制造任务完成状态。
