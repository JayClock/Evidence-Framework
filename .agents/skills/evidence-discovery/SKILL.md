# Evidence 业务访谈

每轮沿「履约判断 → 关键数据 → 凭证来源 → 深入追溯 → 返回判断」推进一个业务焦点，主动成组提出全部独立必要问题，并把回答落成可复核的追溯日志。方法、术语与模型表达归 `evidence-fm`，本包只维护问答、控制与凭证追溯的对话形式。

## Guides

- 读取当前焦点：`.evidence/fm/` 中相关 Entity 及其属性、`.evidence/traces/interview-trace.json` 的最近记录、本轮输入。材料已提供就直接读取，其余必要片段按需读取。
- 专业方法按当前判断从 `evidence-fm` 取用：`business-analysis.md`、`domain-modeling.md`、`provenance.md`、`domain-language.md`、`responsibility-closure.md`、`scenario-validation.md`；一次只取当前判断需要的文件，续问复用未变化内容。业务分析从现金权责与目标—实际对比找到约定与责任双方。
- 导航、追溯与控制的对话样例见 [样例索引](examples/README.md)，只读当前场景需要的章节。
- 统一语言只消费 FM 定义：不为保存术语创建占位 Entity，不另建术语表或英文词典；故事、问题与交接使用同一中文（英文）规范名称。只聊不落盘或仅保存资料时不写模型 JSON。
- 访谈协议见 [访谈协议](references/interview.md)，其中定义单轮路径、展示格式与追溯日志契约。

## Action

1. **承接焦点。** 吸收本轮全部事实、更正与控制意图，从实际文件与最近记录定位当前请求或确认、合同责任方、原问题与停止／暂缓状态；已有目标或单一清晰入口时直接承接，不改写未受影响的结论。完成时：焦点、责任方、授权与控制状态可定位。
2. **沿数据追溯并组织问题组。** 消费已有约定、参数与凭证，判断当前请求或确认能否成立；不能成立时沿关键数据找到直接来源，再按需深入形成依据并逐层返回。重新计算依赖前沿，把共同前提与全部独立必要问题同轮提出，用追溯故事说明判断、证据与缺口。完成时：故事、问题组与必要未知一致，问后等待真人。
3. **核对并保存移交内容。** 按协议核对问答是否满足交付门禁，把回答、确认事实与来源绑定增量写入 `.evidence/traces/interview-trace.json`；模型变更按现有授权交给 FM，范围结束信号交回 `evidence-modeling`。完成时：本轮已保存内容、校验结果与未执行事项分别可定位。

## Sensors

每轮交付前先做推断核查，再跑脚本校验；任一门禁未通过都不交付。

### 推断核查（交付前逐项判定）

- [ ] **责任锚定**：当前位置的责任人是否属于所属合同的一方，实际主体、经办人与证明提供方是否已分开说明？
- [ ] **证明关系**：故事是否说明请求依据或结果证明，而不是用操作先后、点击行为或字段清单代替凭证？
- [ ] **成组完备**：当前前沿中所有互不依赖的必要未知是否已在同轮提出，且没有靠猜测前置答案追问分支？
- [ ] **控制边界**：停止、暂缓、仅补资料与更窄授权是否仍被遵守，未答项没有被当成同意？
- [ ] **正文纯净**：交付正文是否已过滤技能名、参考文件名、页码与内部检查过程，术语是否与 FM 定义一致？

### 追溯日志校验（写入后执行）

```bash
python3 "$DISCOVERY_SKILL_DIR/scripts/check_interview_trace.py" "$TRACE_FILE" \
  --schema "<evidence-fm>/schemas/interview-trace.schema.json" \
  --fm-root "$FM_ROOT"
```

退出码 0 表示结构、问答标识与 Entity 引用均通过；非 0 时按报告修正后再交付，不把未建模的引用写入日志。校验只证明日志可被下游读取，不证明业务判断正确或人类已批准。

## Steer

- **推断核查未通过**：回到 Action 修正故事、问题组或控制表达，不发送未达标内容。
- **日志校验失败**：保留真实错误与已写文件，按报错修复；引用缺失时先交 FM 落地凭证，再重写该条记录。
- **依据不足、来源冲突或确认失效**：交接对象、缺口与影响后停止，不自行推测答案，不解除访谈停止状态。
- **暂缓、停止或仅补资料**：处理获授权内容，保留原问题标识、未决依据与恢复位置后停止；继续问答需要明确意图。
- **完成**：说明当前判断、必要未决项、控制意图、实际保存与校验结果，然后停止；不自动开始下一个合同，不自动进入下游。
