# Evidence 业务访谈

每轮理解全部输入，处理受影响判断，保存明确术语，再围绕同一业务焦点，从相关凭证的依赖前沿成组提出独立的必要问题并等待真人；用户要求一次一问时遵守。问答与控制由本包维护，专业方法由 FM 维护。

## Guides

先读 [访谈协议](references/interview.md)，确定当前节点、原问题、授权与控制意图。首次进入或恢复时加载必要方法；连续问答复用仍在上下文且未变化的方法，只核对新增输入与受影响依赖。

通过资源发现定位 `evidence-fm`，按当前判断读取包内参考：

| 当前判断                                    | FM 包内参考                            |
| ------------------------------------------- | -------------------------------------- |
| 经营依据、合同边界、请求—确认骨架及分析依赖 | `references/business-analysis.md`      |
| 领域复用、业务连接点及必要的内部规则        | `references/domain-modeling.md`        |
| 关键数据、计算与业务时间依据                | `references/provenance.md`             |
| 术语理解、日常表达、定义归属及当轮沉淀      | `references/domain-language.md`        |
| 责任终点、全部追责结束及确认适用性          | `references/responsibility-closure.md` |
| 正常与争议单据推演                          | `references/scenario-validation.md`    |

单点追溯、成组澄清、合同导航或控制与恢复时，从 [行为基线](examples/README.md) 只读对应样例。判断使用实际材料与用户决定；缺少专业资源时交接具体限制。合同或独立领域／协商澄清结束且具备生成权限时，通过资源发现定位 `evidence-modeling`，交回对应建模分支；仅访谈或只读时不扩大权限，完整接续协议由该入口维护。

## Action

1. **更新理解并验证边界。** 吸收本轮全部事实、更正和控制意图；自行查找可查事实，沿依赖核对受影响结论。首次展示总览前及边界受影响时，按 FM 业务分析的分类验证执行 Sensors → Steer：检验运营责任与领域能力，必要时拆分、撤回或保留缺口，不让用户选择代替分类验证。已知事实直接复用，从前置依据已具备的未决判断中选择下一步。完成时，当前判断、依赖及必要未知能由实际业务依据说明。
2. **保存术语。** 按 FM 方法当轮维护唯一词汇表 `.evidence/glossary.json`：未建模概念保存明确的定义，已建模概念引用当前 FM。只聊不落盘、仅保存资料等更窄授权优先。完成时，受影响术语已实际保存或本轮无需写入；术语写入失败立即停止。
3. **推进一个业务焦点。** 按访谈协议执行混合上下文导航、合同凭证或领域对象／协商方案的成组澄清及本轮交接。领域优先复用成熟方案、澄清业务连接点，必要时才深入；角色选择按 FM 语义，不默认创建完整领域上下文。领域与协商按对应位置和依据展示，不强套凭证。展示主焦点、各活跃凭证的当前位置与责任人、简短追溯故事，必要时说明业务目标；按共同依据承接各来源链的深入与回溯，分别编号提出前置依据充分且彼此独立的必要问题；依赖关系不确定或用户要求逐问时只问一题。导航、单合同结束确认、领域／协商分支结束确认及全局结束确认分别单独一轮。完成时，提出本轮问题后等待真人，按停止／暂缓意图结束本轮，或将获授权的有效合同／领域／协商结束信号交回建模入口。

## Sensors

展示与下一轮前核对：分类及受影响边界已经验证，功能清单未被直接当作领域；资料出处与内部检查过程未混入业务展示；全部输入已吸收；已知事实已复用；故事忠实且聚焦当前节点；故事、问题与交接使用同一中文（英文）规范名称；凭证责任不与受益者或证明提供方混淆；共同依据只追一次，各链深度优先、回溯关系准确，多凭证部分回答已分别承接；含义冲突未被静默覆盖；各题前置依据具备且彼此独立；部分回答、未答与暂缓分别承接；更正后重算依赖；术语定义归属与实际保存结果准确；人类确认覆盖当前理解。

## Steer

- **更正**：沿依赖核对结论与确认失效影响，保留未受影响事实。
- **暂缓、停止或仅补资料**：处理本轮获授权内容，保留原问题与未决依据后停止；继续问答需要明确意图。
- **保存失败**：说明真实错误与未保存术语后停止；恢复先核对实际条目，再补齐授权内容。
- **部分回答或取消**：吸收已答内容，未答项不默认同意；取消保留焦点等待。不靠换问题标识恢复暂缓题。
- **本轮交接**：简述当前判断、必要未决项、控制意图和术语实际保存结果；获授权的有效合同／领域／协商结束信号交回建模入口自动接续，其余下一步由用户选择。不自动恢复其他合同或暂缓题。
