# 控制与恢复：吸收事实，按实际权限交接

以下为合成样例；保存结果由实际工具反馈决定，不是预设成功。完整规则见 [访谈协议](../references/interview.md)。

## 1. 已知回答与停止意图同时到达

当前为订阅协议（Subscription Agreement）的退款（Refund）履约，退款申请（Refund Application）由读者（Reader）负责，实际主体未知。Q-010 追溯应退金额（Refund Amount），原支付凭证（Payment Evidence）已证明实付金额（Paid Amount）。用户回答：“适用约定按本笔实付全额退还，只保存术语并停止。”

直接复用约定解释金额，不再询问金额实例；按授权核对定义归属并写入词汇表。[词汇入口](glossary.json)是这一步的合成术语产物。实际保存成功后可交接：

```text
当前位置：订阅协议（Subscription Agreement）→ 退款（Refund）→ 退款申请（Refund Application）〔履约请求〕
责任人：读者（Reader）；实际主体待明确。

应退金额（Refund Amount）的依据已追到适用约定：按本笔实付金额（Paid Amount）全额退还。支付凭证（Payment Evidence）说明实付，约定说明为什么应退同一金额；这不表示退款（Refund）已完成。

本轮明确术语已保存。按要求停止；其他未决责任保留。
```

这里只说明合成情境中已明确的名称与责任，实际输入未给时不补造。保存失败时不使用成功表述，也不继续其他可问分支。

## 2. 写入失败后只补保存

用户补充付款证明的明确含义并允许沉淀术语，环境真实拒绝词汇表写入。吸收事实，说明工具错误及未保存术语，立即停止，不把题面声称当作实际失败证据。

恢复后用户要求“只补术语，不继续问”：先读取实际条目，保留外部新增内容，只补授权内缺失术语；已收到的答案不重问。交接实际保存结果后停止，不宣称未验证的原子写入。

## 3. 更正模型定义不扩大编辑权限

词汇条目引用 FM 的收稿回执，用户更正为“只证明收到，不证明质量合格”，明确不改模型 JSON。定位定义拥有者，说明收到与合格的差异及依赖判断、结束确认的失效影响；不另存一份已建模定义，不修改 FM/API。

## 4. 局部暂缓、整轮停止与跨会话承接

期限题 Q-001 暂缓，用户允许继续金额题，就只推进获准的独立前沿，保留 Q-001 原标识；若新事实说明金额也依赖暂缓项，则重算依赖并说明阻塞，不换号恢复它。

用户随后说“今天全部停止”，再补付款回执并要求“仅补资料”：吸收证明作用，保持停止。新会话仅查看仍不提问；明确允许继续付款确认后，读取必要方法、依据与控制状态，只追获准话题。取消时保留焦点及未答项等待，不默认同意。

问题答完、没有可问前沿或停止，都不等于合同或全局追责结束；相应结束确认独立一轮，不夹在业务问题组中。
