# 按当前动作读取样例

这些合成样例只说明表达与连续承接，不提供当前项目的业务约定。实际判断使用本轮材料、用户决定及 FM 方法；规则由 [访谈协议](../references/interview.md) 唯一维护，每次只读当前动作对应文件的相关章节。凭证追溯以履约判断、关键数据、来源深入和返回判断为一条连续主线；其他样例只覆盖导航、控制和恢复等不同风险，不为同一规则换业务重演。

| 当前动作                       | 读取                                  | 关注点                                     |
| ------------------------------ | ------------------------------------- | ------------------------------------------ |
| 同一履约判断的凭证追溯         | [追溯问答](tracing.md)                | 要求与结果的依据、独立问题、深入后返回判断 |
| 合同／领域／协商导航与分支结束 | [上下文导航](navigation.md)           | 经营目的、边界、焦点选择与人类确认         |
| 更正、暂缓、停止与恢复         | [控制与恢复](control-and-recovery.md) | 原问题、授权、模型定义归属与待改影响       |

维护样例时必须脱敏：使用通用对象、责任角色和独立合成约定，不保留可关联真实平台或客户的专用名称、商品类别、条款组合、身份、地址、链接、日期或交易编号；需要数值时使用明确虚构的测试值。仅替换品牌名或声明“合成”不足以脱敏。保留证明关系、依赖与反例即可，不复制真实业务材料。这是教学材料的维护要求，不授权改写正式业务记录或将实际访谈主体匿名化。
