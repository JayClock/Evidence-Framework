# 访谈行为基线

这些合成样例只约束行为与表达，不替代当前业务材料、人类判断或写入授权。沿实际记录处理当前业务，不把样例中的约定、回答、ID 或保存结果复制进项目。协议与 FM 方法优先于样例；样例与实际依据冲突时停止受影响行动。

按当前动作只读一组，不在每轮加载全部样例：

| 当前动作                           | 样例                                  | 检查重点                                   |
| ---------------------------------- | ------------------------------------- | ------------------------------------------ |
| 单点追溯、已知则推导、领域身份澄清 | [单点一轮](focused-turn.md)           | 位置、自然故事、问题必要性、记录增量       |
| 首次总览、选择、已结束项、取消     | [合同导航](navigation.md)             | 导航与业务问题分离，选择不改变责任范围     |
| 更正、停止、保存失败与恢复         | [控制与恢复](control-and-recovery.md) | 原话先保存，权限不扩大，部分保存不冒充完成 |

每组从输入到记录增量再到展示，随后用反例标明越界原因。展示中的业务凭证名称和信息来源是业务内容；材料路径、版本、来源 ID 留在记录，不进入日常追溯故事。

[退款记录快照](refund-record.json)和[词汇入口](glossary.json)对应单点样例第二轮，沿用现有记录格式，不建立样例专用业务 Schema。它们是期望快照，不是一次真实保存或全局追责结束。恢复时仍读取实际文件，不能凭样例或先前对话判断已经保存。

维护时检查样例引用与词汇结构；访谈质量、保存顺序和越权行为须通过隔离的真实多轮运行检查。示例检查通过不证明 Agent 已遵守协议。
