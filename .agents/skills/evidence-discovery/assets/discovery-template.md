# 访谈记录模板

只使用有内容的部分，沿用项目已有文件和标识。没有既有约定时可用 discovery.md 保存来源与工作理解、questions.md 保存已提问题；不自动整理成正式业务模型，也不迁移或删除旧记录。

- 当前目标与焦点：<本轮讨论内容>
- 已消化来源：<材料版本／定位及最新回答标识>
- 当前实际问题：<原问题 ID、gapKey、原文、定位及待答／已解决状态；没有则明示>
- 暂缓问题：<沿用原 ID 与 gapKey；没有则明示>
- 交互状态：<问答中／等待／已停止及依据；停止后不自动恢复>
- 正式模型位置：<路径或尚无>
- 当前候选与检查记录：<准备结果／检查报告路径或尚无>
- 下一步选择：<继续澄清／形成候选／只校验／保存已展示候选／停止；建议不是授权>

已有事实、回答、模型及案例只引用路径与 ID；尚未保存的必要原话先补入下面的来源记录。没有保存或资料缺失则明示。

## 当前业务切片

- 上下文类型与身份：<channel／contract／domain；依据>
- 凭证责任／协商／对象结构：<已知、部分明确或待明确>
- 请求凭证：<凭证、发起方、接收方、要求、开始时间、截止时间>
- 确认凭证：<凭证、提供方、证明内容、确认时间；不默认审批人>
- 参与者与代表关系：<Role、Party／Player、Representative、Evidence provider 分开>
- 标的物：<Thing 及其与当前切片的关系>
- 异常前序与触发：<有来源的直接链；无则明示>
- 事实覆盖与当前缺口：<按已知／部分明确／待明确列出影响，不写百分比>

纯渠道或领域讨论只保留适用项，不为填模板补造合同、参与方或凭证。第三方上下文通过凭证引用连接，不自动并入当前合同双方。
