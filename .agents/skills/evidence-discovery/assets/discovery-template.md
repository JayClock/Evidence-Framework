# 访谈记录模板

只使用有内容的部分，沿用项目已有文件和标识。没有既有约定时可用 discovery.md 保存来源与工作理解、questions.md 保存已提问题；不自动整理成正式业务模型，也不迁移或删除旧记录。

## 当前交接

- 当前目标与焦点：<本轮讨论内容>
- 已消化来源：<材料版本／定位及最新回答标识>
- 当前问题与暂缓项：<原问题 ID、定位及状态>
- 交互状态：<问答中／等待／已停止及依据>
- 下一步选择：<建议，不是授权>

已有事实、回答、模型及案例只引用路径与 ID；尚未保存的必要原话先补入下面的来源记录。没有保存或资料缺失则明示。

## 来源与工作理解

| 来源标识 | 原始材料／回答定位及版本 | 必要原话 | 临时理解、疑点或冲突 |
| -------- | ------------------------ | -------- | -------------------- |

工作术语、对象关系和讨论案例可作为临时理解记录，但不形成另一份正式词汇表、规则清单或验证套件。已有正式内容直接引用；原话、明确事实、推导、假设和未知分别标明。

- 已知依据与判断缺口：<引用及影响，不重复正文>
- 状态：<待答／暂缓／已解决／依据失效>
- 回答：<用户原话或原记录引用，未答则明示>

只记录已经提出的问题，其余疑点留在工作理解，不生成预排问卷。更正不抹去原话，暂缓不变成范围排除。
