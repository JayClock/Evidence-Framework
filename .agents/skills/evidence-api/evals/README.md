# API 设计行为评测

[evals.json](evals.json)维护独立 `evidence-api` 的整体设计、只读校验、投影与失败边界，保留原案例 ID。`files_base: ".."` 表示输入相对 Skill 根解析；商品采购案例使用整个 `examples/full-lifecycle/`，包含合成 FM、场景和 API。样例不是业务来源或准入确认。

在独立临时项目和新会话中提供题述来源、本包以及通过显式路径定位的 FM 包。已有有效 FM 结果直接交接；没有时只调用 FM 的只读检查一次，API 复用结果及摘要，不修改 FM 或重新组织业务确认。讨论不要求运行依赖，只读不写项目文件。

同一输入分别运行新旧版本或有／无 Skill，不共享答案。记录实际读取、执行顺序、命令退出码、文件差异和逐项 expected_output 判定，核对整体对象／场景覆盖、HTTP 契约、消费者接续、静态与运行时边界。API 缺口不得反向修 FM 或通过局部输出掩盖。

这些行为评测由独立会话与真人评价，不交给 FM 技术产物评分器。结构和功能回归见 [测试说明](../tests/README.md)，不证明 Agent 的设计或路由质量。没有实际执行就标未执行，不填写通过率或业务批准。
